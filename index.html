Import LPO Orders & GRN from Excel

Choose an .xlsx or .xlsm file. The system detects automatically whether it is an LPO document (Local Production Order), a GRN, or an Orders/GRN table, and ignores hidden sheets. Several rows with the same LPO No become one LPO with many lines. GRNs are added first, then orders are deducted. Rows already imported are skipped, and rows starting with "EXAMPLE" are ignored.
